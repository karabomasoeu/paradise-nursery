# Paradise Nursery 

A React and Redux shopping application for a houseplant nursery.

## Project Name
**Paradise Nursery** 

## Features
-  12 unique houseplants across 4 categories
-  Redux-powered shopping cart
-  Add, increase, decrease, and remove items
-  Live cart totals and item counts
-  Responsive design

## Tech Stack
- React 18 and Vite
- Redux Toolkit and React-Redux
- React Router DOM

## Getting Started

```bash
npm install
npm run dev
```

## Pages
1. **Landing Page** (`/`) - Company intro with Get Started button
2. **Product Listing** (`/plants`) - Browse plants by category
3. **Shopping Cart** (`/cart`) - Manage cart items and checkout
